rig

A minimal agent-loop machine: assemble context, stream the model's output, execute what it asks for, feed the results back, repeat.

Install the release binary for your platform:

curl -fsSL https://mrsirg97-rgb.github.io/rig/install.sh | sh

Or, with Go ≥ 1.26:

go install github.com/mrsirg97-rgb/rig/cmd/rig@latest
