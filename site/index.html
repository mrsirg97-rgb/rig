ten native tools ship in the box. each is a leaf behind the Tool seam; every call observed by the walls, bounded, and named:
bash real subprocesses; output surfaced and bounded
file read · write · edit; edits drift-checked against what you read
fs ls · find · grep; small schemas a local model can reach
diff the working tree vs HEAD, or the last observation of the same call
python a persistent IPython kernel; state persists across calls
web search and fetch; the fetch carries the SSRF guard
todo the task queue; event-sourced, DAG-validated at create
rem memory; recall by intent, consolidation arithmetic
scheduler background jobs on cron; the worker runs in a bwrap jail
plugins_reload re-discover from disk; the swap takes effect next turn

one file under ~/.rig/plugins/ is one tool. the name is the filename; the description and schema are the file's; the call rides the shared python kernel. a loaded tool registers on the same seam as the native set, indistinguishable on the wire. a broken file names itself and is skipped; it never bricks the harness. an installed plugin is its own allow-list entry: it arrived by your approve, not by an allow line.
● bash · $ cat ~/.rig/plugins/uptime.py
DESCRIPTION = "report host uptime, terse"
SCHEMA = {"type": "object", "properties": {}}
def run(args: dict) -> str:
s = open("/proc/uptime").read().split()[0]
return f"up {int(float(s) // 3600)}h {int(float(s) // 60) % 60:02d}m"
