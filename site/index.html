what it is

rig turns the model on your desk into something that works. Point it at your repo and it reads the code, edits it, runs the tests, and remembers what it learned. One binary, one endpoint, one terminal.

It is small enough to read before you trust it. The loop is a few hundred lines, and everything around it plugs in: tools, guardrails, schedules, workers. Sessions stay fast for hours because the prompt never wobbles, so the cache does the work.

Close the laptop. Pick the session back up from your phone.

getting set up

1

Install it

One file lands in your path. Signed releases, and it updates itself in place.

curl -fsSL https://tryrig.ai/install.sh | sh
✓ rig {{RIG_VERSION}} installed to ~/.local/bin/rig

# later
rig -update

2

Point it at a model

Anything that speaks the OpenAI API: llama.cpp, llama-swap, Ollama, or a hosted key. Local is the default.

~/.rig/settings.json

{ "model": "local" }

~/.rig/models.json

[
  { "id": "local",
    "baseUrl": "http://127.0.0.1:8090/v1",
    "window": 262144 }
]

3

Run it in a repo

The terminal opens. Ask for something real. Reads run in parallel, results land in order, and the transcript still reads top to bottom.

cd your-project && rig
❯ look around, run the tests in the background, remember what you learn

● todo · create   0/3 · next t1
● read · AGENTS.md
● find · PACKAGE.md
● grep · interface ./core
  three reads admitted together · results applied in call order
  batch ✓ 0.08s

4

Let it run things for you

Hand off the slow part to a worker, or put a job on real cron. Workers are sandboxed and keep a transcript you can resume.

❯ /swarm 2
swarm: added 2 agents · worker w1 claimed t2 · worker w2 claimed t3

❯ /scheduler create health check the fund and note anything odd 0 */2 * * *
scheduler: j8 health · every 2 hours · next fire 14:00

5

Come back later

Everything is on disk in the repo: tasks, memory, schedules, sessions. Resume from the phone over SSH, or glance at the dashboard.

rig -resume 1a0d99397efd
session 1a0d99397efd · 214k up · 3 todo · 1 job · resumed

rig was built by hand until it could finish one turn. Everything after that was written by local models running inside rig, from a phone. The git log is the receipt.
