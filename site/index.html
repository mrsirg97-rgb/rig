assemble · stream · execute · repeat

what rig is

rig is a minimalist agentic harness. one job: the turn — assemble context, stream the model's output, execute what it asks for, feed the results back, repeat. every dependency held at a typed seam, every induced work bounded, and the harness names no concrete type.

plugins

one file under ~/.rig/plugins/ is one tool: the name is the filename, the description and schema are the file's, and the call rides the shared python kernel. loaded tools register on the same seam as the native set — indistinguishable on the wire. a broken file names itself and is skipped; it never bricks the harness.

tools

ten native tools, each a leaf behind the Tool seam — every call observed by the walls, bounded, and named.

  • bash — real subprocesses; output surfaced and bounded
  • file — read · write · edit; edits drift-checked against what you read
  • fs — ls · find · grep; small schemas a local model can reach
  • diff — the working tree vs HEAD, or the last observation of the same call
  • python — a persistent IPython kernel; state persists across calls
  • web — search via SearXNG; fetch with the SSRF guard and extraction
  • todo — the task queue; event-sourced, DAG-validated at create
  • rem — memory; recall by intent, consolidation arithmetic
  • scheduler — background jobs on cron; the worker runs in a bwrap jail
  • plugins_reload — re-discover from disk; the swap takes effect next turn

install

installer POSIX sh · checksums verified before anything moves · lands in ~/.local/bin · linux and darwin, amd64 and arm64 
❯ curl -fsSL https://mrsirg97-rgb.github.io/rig/install.sh | sh
release binary the same asset the installer fetches — pick rig_<os>_<arch>, the version lives in the URL 
❯ curl -fsSL https://github.com/mrsirg97-rgb/rig/releases/latest/download/rig_linux_amd64 -o rig
❯ chmod +x rig && ./rig --version
go install needs Go ≥ 1.26 — the core is stdlib-only; the one leaf is a pure-Go sqlite driver 
❯ go install github.com/mrsirg97-rgb/rig/cmd/rig@latest
then talk any OpenAI-compatible endpoint — a local server, a gateway, a hosted API. the wire protocol only. 
❯ rig --base-url $ENDPOINT --model $NAME
