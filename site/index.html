the shape is clear. rig is one closed machine: assemble context, stream the model, execute its calls, return the results, repeat.
• the loop is small, frozen, and protected by a structural test. growth stays behind typed seams.
• tool calls run in parallel on an event loop: goroutines post completions, one consumer applies them in call order. no locks, no races, the transcript stays ordered.
• the walls are named. an allowlist, a retry guard, an approval gate, result bounds, a plugin landing zone, a bwrap jail for background workers, and every refusal says why, so the model adjusts instead of flailing.
• memory is deliberate. nothing writes itself into your prompt; the model recalls, learns, and supersedes by id. tasks, memory, and schedule are scoped to the repo; worktrees share one plan.
• every behavior is a sentence in specs/ with a test pinning it; the wire is byte-pinned against golden request bodies. specs first, then failing tests, then code.
• one static binary, stdlib-only core. TUI, piped CLI, headless workers, and a phone-sized dashboard share the same stores.
the models running inside rig build rig. this page describes the harness they use.

fileread · write · edit; edits drift-checked against what you read
fsls · find · grep; small schemas a local model can reach

pythona persistent IPython kernel; state persists across calls
websearch and fetch; the fetch carries the SSRF guard

remmemory, deliberate; recall by intent, supersede by id, scoped to the repo
schedulerbackground jobs on cron; the worker runs in a bwrap jail
delegateone-shot worker; run a task on a fresh session, get back its last message
pluginrun a plugin, or read its contract; the hot path never pauses
pluginsthe ecosystem: list · create · delete · reload; a new plugin lands untrusted in the pending zone until you approve it
sessionsthe session store, read-only: the recent sessions and the soak's vitals; the models, the faults, the cache ratio
── one file, one tool ──────────────────
drop one python file under ~/.rig/plugins/. no manifest, build step, or restart. model-authored files land in pending until you approve them.
● bash · $ cat ~/.rig/plugins/uptime.py
DESCRIPTION = "report host uptime, terse"
SCHEMA = {"type": "object", "properties": {}}
def run(args: dict) -> str:
s = open("/proc/uptime").read().split()[0]
return f"up {int(float(s) // 3600)}h {int(float(s) // 60) % 60:02d}m"
